/ 做什么

一台你自己跑的记忆服务，
三个面各管一件事。

Agent 通过插件自动写入和注入，通过 MCP 主动存取，人通过网页查看和整理。数据库走远端 Postgres。Meilisearch 和 Qdrant 按需再配。

自动记下

插件接在会话上：开场注入相关记忆，每条提问前再补一段，工具调用后记一笔观察，会话结束生成摘要。请求超过 2 秒就放弃，失败事件落在本地 spool 之后补投。

载体 · plugins/ 四种宿主插件

主动存取

stdio MCP 服务把记忆库暴露成 66 个 memory_* 工具。Agent 用它们保存事实、按问题召回、改出新版本、忘掉、整理。MCP 进程只转发 HTTP，存储和检索都在服务器上。

写入前会做隐私清洗——API key、Bearer token、PEM 和写在 <private> 里的内容都不会进库。编辑不覆盖旧文本，而是挂上新版本，检索只认最新版。

/ 怎么用

四条命令，
让它开始记。

需要 Node.js 22 和 pnpm 10。令牌只在网页里签发，只显示一次。

  1. 启动服务和网页

    仓库根目录 pnpm install && pnpm dev，网页在 5178，接口在 8787。

  2. 注册，签发一把令牌

    登录后进「MCP 客户端」注册客户端，拿到可粘贴的配置和一把 arm_ 令牌。

  3. 构建 MCP 入口，交给 agent

    pnpm --filter @agent-recall/mcp build，把右边的配置贴进 agent。

  4. 让它存，再让它找

    说「记住我们用远端 Postgres 做默认数据库」。下一场会话，它会自己想起来。

/ 工具

66 个工具，
日常只用这一小把。

全部由 MCP 暴露。写入与遗忘、召回、浏览、整理，按场景分组，网页里可以按名字和用途筛选。

66 个工具
memory_remember

用户明确说「记住」时用，保存一条事实或偏好。

写入
memory_recall

针对一个具体问题做词法和向量融合召回。

召回
memory_context

返回按 token 预算裁好的上下文，直接放进提示词。

召回
memory_lesson_save

把一条教训存成 lesson：什么发生了，下次怎么做。

写入
memory_update

编辑一条记忆，生成新版本，旧版本留在版本链里。

写入
memory_next

开场简报：未完成的行动、最近一场会话、最新 5 条记忆。
