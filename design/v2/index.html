整体布局改了什么

  • 内容列不再贴住左导航：.stage 改为弹性居中，页面按性质分三档宽度 —— 标准 1120px、窄页 760px（设置/令牌/MCP）、宽页 1360px（关系图）。宽屏下左右留白对称，视觉重心回到中间。
  • rail 从 232px 收到 224px，导航加分组（记录 / 洞察 / 系统），激活态改为左侧渐变刻度线 + 浅底。
  • 页眉统一：宋体标题 + 一行说明 + 右侧主操作，说明文字限定 56ch。

每个页面改了什么

  • 记忆：四张统计卡收成页眉下一条 hairline 数据带；搜索成为页面主体（召回/精排是输入框内的分段开关）；三行平铺筛选收进「筛选」按钮，已选条件以可移除 chip 显示。
  • 会话：手风琴改为左 360px 会话列表 + 右侧时间线详情的主从布局，可以边选边看。
  • 状态：9 个 chip tab 改为页内竖向侧栏（图标 + 名称）；行动、信号等面板重排为任务行 / 定义行。
  • 关系：chips + 列表改为 SVG 图可视化 + 图例 + 右侧节点详情。
  • 治理：7 个堆叠 panel 改为顶部健康摘要 + 双列操作卡栅格，危险操作统一二次确认样式。
  • 设置：左锚点导航 + 右分节表单，不再一屏滚到底。
